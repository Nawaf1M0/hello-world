## task-manager

A customizable task management web app lives in [`task-manager/`](task-manager/).
It starts with the basics (a kanban board, statuses, priorities, tags, due
dates) and lets you customize statuses, priorities, tags, custom fields, and
appearance from a Settings screen — see [`task-manager/README.md`](task-manager/README.md)
for details and how to run it.
